ARK Server Manager v1.16.0
=========================

このPCの D:\arkserver にある ARK: Survival Evolved 専用サーバー用の管理アプリです。

使い方
------
1. 「ARK Server Manager.exe」をダブルクリックします。
2. 初回は「起動設定」と「ゲーム設定」の内容を確認し、「設定を保存」を押します。
3. 「ダッシュボード」の「サーバーを起動」を押します。
4. 停止するときは「安全に停止」を押します。

ゲーム設定
----------
「ゲーム設定」では、非専用セッションのホスト画面でよく使う項目を設定できます。
各項目にはARKの標準値を併記しています。

保存した内容は次回のサーバー起動時に反映されます。
建造物関連の設定は Game.ini にも反映し、変更前の内容を Game.ini.arkmanager.bak に保存します。
画面幅に収まらない設定は、パネル下部の横スクロールバーで移動できます。

サーバー操作
------------
サーバーの起動完了後に「サーバー操作」タブが使用できます。

・ゲームへのコマンド入力
  RCONコマンドを入力して送信します。
  例: ListPlayers、Broadcast メッセージ、SaveWorld

・恐竜検索（負荷を抑えた2段階方式）
  1. 恐竜名を日本語で入力または五十音順の一覧から選びます。
  2. 検索対象を選び、「数を検索」を押します。
  3. 個体が見つかったときだけ「場所を検索」が有効になります。
  4. 必要な場合だけ「場所を検索」を押します。場所はレベルが高い順に最大100個体まで表示します。
  5. 表示された座標行を選び、「マップへ追加」を押します。最大5体まで追加できます。
  6. 「選択中を表示」を押すと、追加した個体を色分け・番号付きのピンで表示します。
  7. 地図上のピンまたは上部の個体ボタンを押すと、現在選択中の個体が大きな白枠で強調されます。

  「すべて」「野生のみ」「テイム済みのみ」は、直近のサーバー保存データから検索します。
  野生／テイム済みの分類、レベル、場所が同じ保存時点になるため、結果の食い違いを防げます。
  検索結果には、基準にした保存日時も表示します。
  野生個体はARK内の個体IDを使って現在＋直近4つの時刻付き.arkバックアップを照合し、
  5セーブすべてで位置差が1m未満ならレベル横に「［死］」を表示します。
  ARKの休眠中も位置が変わらないため、これは死亡確定ではなく、障害物内などの現地確認が必要な警告です。
  テイム済み個体は待機中の誤判定を避けるため「［死］」判定の対象外です。

  フィヨルドに出現する通常種、固有種、変種、R種、X種、TEK種、アルファ種を一覧から選べます。
  シャドウメイン、カルキノス、メイウィング、マグマサウルスなどにも対応しています。
  フィヨルドの場所検索では、各座標にアスガルド、ヴァナヘイム、ヨトゥンヘイム、
  またはミッドガルド内の島名（ヴァナランド等）を併記します。
  座標はGPS緯度・経度とZ座標で表示します。スマホ画面からも個体を選んでマップ表示できます。
  スマホでは座標一覧のチェック欄から最大5体を選択し、地図上のピンをタップして表示対象を切り替えます。
  ピンは実際のフィヨルド地図画像にGPS座標を重ねます。異世界の座標も同じ地図上へ目安として表示します。
  地図の横線は緯度、縦線は経度です。10刻みの数字と線に合わせてピン位置を補間表示します。
  島の海岸線や洞窟は大まかな領域判定のため「海域・洞窟」と表示される場合があります。

  検索はボタンを押したときだけ実行され、常時スキャンしません。
  保存データの大きさにより、分類検索に数秒かかることがあります。

低温ポッド
----------
ゲーム設定の「低温クールダウンを無効化」を有効にすると、次回サーバー起動時から
低温ポッドを連続使用でき、解凍した恐竜がクライオシックネスで気絶しない設定を適用します。
v1.14.0以降はGameUserSettings.iniだけでなくサーバー起動コマンドにも同じ設定を渡すため、PvPサーバーにも確実に反映されます。

起動・停止の日時指定
--------------------
ダッシュボードの「日時指定」では、次の2種類を同時に設定できます。

・単発の起動／停止
  日付欄と時刻欄をそれぞれ指定して一度だけ実行します。実行後は自動的に解除されます。

・毎日の定時起動／定時停止
  「毎日起動」「毎日停止」を有効にして時刻を選ぶと、毎日その時刻に実行します。
  日付をまたぐ「毎日23:00停止／翌日08:00起動」のような設定にも対応します。

停止はどちらもSaveWorldの後にDoExitを送る安全停止です。
日時指定はARK Server Managerが起動している間に実行されます。PCのスリープ中や管理アプリ終了中は、
次にアプリを開いた時点で最後に到来した起動／停止の状態を一度だけ適用し、同じ予約を重複実行しません。

追加機能
--------
ARK Server API 3.56とExtended RCON 3.4をサーバーへ導入済みです。
バックグラウンドでの自動プラグイン再読み込みは無効にし、不要なSaveWorld処理を発生させません。

小型資源スポット（Fjordur限定）
--------------------------------
サーバーの起動完了後、「資源マップ」タブの「現在量を取得」を押します。
公式Fjordur資源マップを基準にした資源豊富エリアについて、現在残っている
金属岩・水晶岩・黒曜石岩のノード数を地図と一覧へ表示します。
基準マップ: https://ark.wiki.gg/wiki/Resource_Map/Fjordur

・「すべて／金属／水晶／黒曜石」で表示対象を絞れます。
・一覧または地図の番号を押すと、選択中の小型スポットが白枠で強調されます。
・アスガルド、ヴァナヘイム、ヨトゥンヘイムは同じ地図に重ね、世界名を併記します。
・1区画は0.35 GPS四方、表示円はGPS半径約0.25です。対角方向でもアルゲンタヴィスでおよそ3秒未満を目安に細分化しています。
・資源岩が合計5個以下の小規模スポットは一覧・地図へ表示しません。
・ピン座標には区画中央ではなく、そのスポット内で検出した資源岩の実座標平均を使用します。
・数値は採取可能で現在残っているノード数です。採取や再生成に応じて変化します。

ResourceProbeは読み取り専用のArkApiプラグインです。起動時・定期・常時の走査は行いません。
管理アプリで「現在量を取得」を押した時だけ9つの元エリアを順番に1回走査し、実際の資源位置を小型スポットに分けて返します。通常約10～20秒かかります。

ResourceProbeの診断・切り離し
-----------------------------
「ResourceProbe 管理」フォルダーに、緊急無効化・再有効化・診断手順があります。
サーバー稼働中はRCONの ResourceProbe.Pause で走査だけを直ちに停止できます。
完全に切り離す場合はサーバーを安全に停止してから ResourceProbe-Disable.cmd を実行します。
更新前ファイルは「ResourceProbe 管理\Backups」に保存します。

主要野生恐竜の埋まり救出（DinoSpawnGuard）
-------------------------------------------
セーブが完了した時だけ、現在読み込まれている主要な野生恐竜を走査します。
地形や建造物のブロッキング形状に食い込んだ個体は、元の場所から最大2500 Unreal Unit以内で
安全地点を探して再配置します。安全地点がなければ削除せず、そのままログへ失敗を残します。

標準対象は大型・実用級の陸上／洞窟生物28系統です。レックス、ギガノト、カルカロ、
シャドウメイン、アンドリューサルクス、カルキノス、ロックドレイク、マグマサウルスなどを含みます。
テイム済み、飛行、完全水棲、ボス、アルファ、意図的に潜る生物は対象外です。

状態確認と即時一時停止は管理アプリのRCON欄から実行できます。
  DinoSpawnGuard.Status
  DinoSpawnGuard.Pause
  DinoSpawnGuard.Resume
完全に切り離す場合は、サーバー停止後に「DinoSpawnGuard 管理」フォルダーの
DinoSpawnGuard-Disable.cmdを実行します。ResourceProbeとは独立しています。

「ARK Dino Search.exe」は野生／テイム済み検索に必要です。
「ARK Server Manager.exe」と同じフォルダーに置いたまま使用してください。

スマホ操作
----------
1. PCとiPhoneの両方でTailscaleを接続します。
2. PCでARK Server Managerを起動し、「スマホ操作」タブを開きます。
3. 「スマホ接続を有効化」を押します。
4. 初回にWindowsの確認画面が出た場合は「はい」を押します。
5. iPhoneのSafariで http://100.100.176.17:8765 を開きます。
6. PC画面に表示された6桁PINでログインします。

スマホから、サーバーの起動／安全停止、稼働状況、ログ確認、RCONコマンド、
恐竜の数・レベル・場所検索に加えて、単発および毎日の日時設定を保存・解除できます。
起動設定とゲーム設定の変更はPC側だけです。

スマホ画面はPCのTailscale IPだけで待ち受けます。
WindowsファイアウォールもTailscaleのアドレス帯（100.64.0.0/10）からの接続だけを許可します。
通常のLANやインターネットには公開しません。
PC側でARK Server Managerを終了すると、スマホ画面も操作できなくなります。
Windows起動直後など、管理アプリより後にTailscaleのIPが準備された場合は、
管理アプリが約2秒間隔で待受を自動再試行し、接続可能になった時点で復旧します。

画面で確認できるもの
--------------------
・起動／停止状態
・ShooterGameServer起動後から接続受付開始までの「起動中」状態
  「Server: \"サーバー名\" has successfully started」がログに出た後、「稼働中」へ切り替わります。
・稼働時間
・CPU使用率
・メモリ使用量とPC全体に対する使用率
・ゲームポートの待受状態
・ShooterGame.log の最新内容（ファイル更新を検知して即時反映）
  起動中にShooterGame.logが0バイトの環境では、ShooterGameServerのコンソールを直接読み取って表示します。

停止について
------------
通常はRCONで SaveWorld を実行した後、DoExit で安全に終了します。
RCONへ接続できない場合のみ、画面から強制終了を選択できます。

設定の保存先
------------
アプリの設定は次の場所へ保存されます。
%APPDATA%\ARK Server Manager\settings.xml

参加パスワードと管理パスワードは、現在のWindowsユーザーだけが復号できる形式で保存します。
既存の Game.ini と GameUserSettings.ini は、このアプリから一括置換しません。
