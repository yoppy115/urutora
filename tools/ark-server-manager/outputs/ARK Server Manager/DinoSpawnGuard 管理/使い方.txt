DinoSpawnGuard v1.0
=====================

目的
----
セーブ完了を検知した後、現在読み込まれている主要な野生恐竜だけを走査し、
地形・建造物などのブロッキング形状に食い込んでいる個体を近くの安全地点へ移します。
起動直後・定期時刻・手動操作では走査しません。

安全条件
--------
・対象は生存中、野生、非アタッチ状態、config.jsonのホワイトリスト内だけです。
・テイム済み、飛行、完全水棲、ボス、アルファ、意図的に潜る生物は標準対象外です。
・移動先は元座標から最大2500 Unreal Unit以内です。
・安全地点が見つからなければ何も消さず、ログへ失敗を残します。
・一度に50体ずつ処理し、セーブ直後の負荷集中を避けます。
・休眠してメモリに読み込まれていない個体は、その回の走査対象になりません。

稼働中の確認と停止（管理アプリのRCON欄）
------------------------------------------
DinoSpawnGuard.Status  状態と直近・累計件数を表示
DinoSpawnGuard.Pause   走査待ちと処理中の走査を破棄し、その場で一時停止
DinoSpawnGuard.Resume  再開。次に完了するセーブまで待機

完全な切り離し
--------------
ARKサーバーを安全停止してから DinoSpawnGuard-Disable.cmd を実行します。
次回起動からDLLが読み込まれません。戻す場合は DinoSpawnGuard-Enable.cmd です。
ResourceProbeとは別プラグインなので、こちらを無効化しても資源検索には影響しません。
