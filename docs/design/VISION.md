# Vision

**Status:** Baseline

**Scope:** ゲームの憲法。個別の計算式やバランス値は置かない。

## Core experience

```text
観測 -> 予測 -> 期待 -> 逸脱 -> 結果 -> 解釈
```

プレイヤーは世界を直接支配するのではなく、自律的に変化する世界へ限定的に介入する。

## Principles

1. 各システムは単独なら理解可能であること。
2. 複数システムが相互作用した全体は、完全には予測できないこと。
3. 大きな逸脱を、根拠のない大乱数で作らないこと。
4. 乱数は小さな揺らぎを作り、その影響がシステム間を伝播して大きな逸脱になること。
5. プレイヤーに与えるのは万能な管理権限ではなく、観測・判断・限定的介入の余地であること。
6. 起きた出来事を後から因果として解釈できる余地を残すこと。

## Guardrails

- NPCの主観と世界の客観状態を同一視しない。
- 内部数値の全公開を、理解可能性の代わりにしない。
- 表示演出がなくても世界の規則を実行・検証できるようにする。
- バランス値や個別アルゴリズムを、この文書へ固定しない。

## Proposed review question

次は元の方向性から導いた評価用の問いであり、まだ確定仕様ではない。

プレイヤーが「偶然そうなった」ではなく、「小さな誤認や選択が巡り巡って、こんな世界になった」と語れるか。
