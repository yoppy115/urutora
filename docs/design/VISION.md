# Vision

**Status:** Baseline

**Scope:** ゲームと制作の憲法。個別の計算式やバランス値は置かない。

## Project purpose

- 販売・販促ではなく、制作者本人の感情的満足を最大化するために作る。
- 完成そのものを絶対目標にしない。プロトタイプで終わることも許容する。
- 後からアイデアやシステムを追加、削除、再構成しやすい構造を重視する。

## Core experience

```text
観測 -> 予測 -> 期待 -> 逸脱 -> 結果 -> 解釈 -> 次の観測
```

プレイヤーは世界を直接支配するのではなく、自律的に変化する世界へ限定的に介入する。次の結果を見たくなるテンポを重視する。

## Emergence of deviation

逸脱は独立した一つのシステムではない。人物、認識、情報、戦闘、疾病、繁殖、集団、概念、困難、上位存在、プレイヤー介入、世界継承などの相互作用から創発する結果である。

特に、Realityと主観の差、同じ事実に対する異なる解釈、情報の変形を重要な逸脱源とする。

## Principles

1. 各システムは単独なら理解可能であること。
2. 複数システムが相互作用した全体は、完全には予測できないこと。
3. 大きな逸脱を、根拠のない大乱数で作らないこと。
4. 乱数は小さな揺らぎを作り、その影響がシステム間を伝播して大きな逸脱になること。
5. プレイヤーに与えるのは万能な管理権限ではなく、観測・判断・限定的介入の余地であること。
6. 起きた出来事を、完全な因果調査を強制せずに後から解釈できる余地を残すこと。

## Three layers of evolution

```text
個体進化: 繁殖・淘汰 -> 能力・評価係数の分布が変化
社会進化: 学習・文化・集団適応 -> 行動様式が変化
世界進化: 概念・困難・再編 -> 次世界の可能性空間が変化
```

三層は独立せず、互いの結果を次の層の入力にする。

## Guardrails

- NPCの主観と世界の客観状態を同一視しない。
- プレイヤーも通常プレイではReality全知にしない。
- 内部数値の全公開を、理解可能性の代わりにしない。
- 表示演出がなくても世界の規則を実行・検証できるようにする。
- バランス値や個別アルゴリズムを、この文書へ固定しない。
- LLMに世界の権威的な状態遷移を決定させない。

## Canonical summary

単純な個体・概念・困難から始まり、主観を持つ住民たちが世界へ適応し、その適応と誤解と歴史が次世界の上位存在・詩篇・新たな困難へ変換されることで、世界そのものが世代を超えて進化していく観測型シミュレーション。

プレイヤーは世界を完全支配せず、限られた啓示を投げ込み、世界から返ってくる予想外の答えを見る。
