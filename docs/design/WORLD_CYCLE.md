# World Cycle

**Status:** Draft

## Confirmed direction

- 世界はプレイヤー入力を待つだけの盤面ではなく、自律的に進行する。
- プレイヤー体験の循環は `観測 -> 予測 -> 期待 -> 逸脱 -> 結果 -> 解釈` とする。
- シミュレーションは表示層と分離し、同じ初期状態とseedから再実行できるようにする。
- 処理順が結果へ影響するため、実装前にサイクルの順序を明文化する。

## Simulation cycle

次の項目はまだ確定していない。確定前にコード上の暗黙仕様へしない。

1. 時間単位: 固定tick、イベント駆動、または混合方式。
2. Reality更新、知覚更新、意思決定、行動解決の順序。
3. 同一tick内の競合を解決する規則。
4. NPCごとの意思決定間隔と、世界時間との関係。
5. プレイヤー介入を適用するタイミング。
6. snapshot、save/load、replayの境界。

## Definition of ready

最初のシミュレーション実装へ進む前に、少なくとも以下を例付きで決める。

- 1サイクルの入力と出力。
- 更新フェーズの順序と、各フェーズが読める状態。
- seedと初期状態を保存する形式。
- 10〜100サイクルをヘッドレス実行する検証方法。
