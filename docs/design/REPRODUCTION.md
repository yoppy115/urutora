# Reproduction

**Status:** Draft

繁殖、継承、突然変異を扱う文書。元の会話では「危険選好を含む遺伝評価パラメータ」と「mutation rate」が話題に出たが、正式なモデルはまだ決まっていない。

## Working constraints

次は元の会話に明記された全体原則を繁殖へ適用した仮の制約であり、ゲーム企画の正史移植時に再確認する。

- 遺伝や突然変異に乱数を使う場合、seedで再現可能にする。
- 突然変異率などの調整値はコードへ埋め込まず、設定へ分離する。
- NPCが繁殖を選ぶなら、その判断は他の行動と同じく主観情報に基づく。

## Required decisions

- 繁殖の成立条件、コスト、時間。
- 親の選択と、当事者ごとの意思決定モデル。
- 継承する値と、学習・文化・環境で変わる値の境界。
- 継承、交叉、突然変異の計算方法。
- 個体数制御、世代交代、死亡との関係。
- 系譜を保存する範囲と、実験ログで追跡する識別子。
- 遺伝パラメータを、ゲーム上観測できる差とどう結び付けるか。

## Definition of ready

実装前に、小さな家系を固定seedで再生できる具体例と、不変条件を定義する。
