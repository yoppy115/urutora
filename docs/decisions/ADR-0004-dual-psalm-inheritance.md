# ADR-0004: Higher entities and psalms inherit different truths

- **Status:** Accepted
- **Date:** 2026-08-16

## Context

前世界の人物本人と、その人物が歴史上どう語られたかは一致しない。両者を一つのデータへ統合すると、主観差と物語化による逸脱を失う。

## Decision

次世界へ二系統の継承を行う。

- 上位存在本人は、前世界での実際の性質、主観、行動傾向を引き継ぐ。
- 詩篇は、住人のPerception、History、重要なピンから、その人物がどう認識・物語化されたかを引き継ぐ。

本人と詩篇の矛盾を許容し、その矛盾を次世界の逸脱源にする。

滅亡・再編フェーズでは、簒奪または授与によって上位存在の力の継承を発生させる。

## Reasons

- Realityと物語の差を次世界へ持ち越す。
- 世界が自分自身をどう解釈したかをゲーム進行へ利用する。
- 数値強化だけではない世界継承を作る。

## Consequences

- 上位存在本人、History、Psalmを別のschemaで保持する必要がある。
- 詩篇生成元のログとピンを追跡可能にする必要がある。
- 簒奪・授与の成立条件と候補選択はDraftとして設計する。
- 次世界で本人と信仰圏が対立し得る。

## Rejected alternatives

### Higher entity and psalm share one canonical personality

実体と物語の乖離が失われる。
